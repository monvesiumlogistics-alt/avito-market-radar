# Где остановились (2026-10-02)

Готово: код, 23 теста, живой прогон на Avito (выдача парсится, дубли не шлются).
Не готово: подключение Telegram-бота.

## Следующие шаги

1. В Telegram: @BotFather → `/newbot` → имя → username на `bot` → скопировать токен.
2. Открыть своего бота → «Запустить» (`/start`).
3. `notepad C:\Users\Administrator\Desktop\avito-hunter\.env` → вставить токен в `TELEGRAM_BOT_TOKEN=` → сохранить.
4. Сказать Claude «готово» — он сам впишет chat id, запустит бота и проверит.

Запуск вручную: `.\.venv\Scripts\python -m app.main` (из папки проекта).

## Решения
- Работает на своём ПК, без прокси. Прокси (`AVITO_PROXY`, мобильный/резидентный РФ) — только если придёт алерт блокировки.
