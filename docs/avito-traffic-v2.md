# Avito Traffic V2 — дизайн

Дата: 2026-10-04. Статус: **предложение, ждёт подтверждения**. Основание: `docs/avito-rate-limit-research.md`.
Принцип: **каждая навигация на Avito проходит через одну точку**, которая знает темп, суточный объём, состояние
блока и приоритет. Без Redis/очередей: asyncio + SQLite, один процесс, один Chromium.

---

## 1. Схема

```
 MarketCrawler(sweep) MarketCrawler(deep/report) recheck   Scanner(monitor)
          │                    │                   │            │
          └──────────── traffic.acquire(kind) ─────┴────────────┘   ← ждёт интервал / отказывает (бюджет, HALTED)
                               │
                        AvitoTraffic  (app/providers/traffic.py)
                        • min interval + jitter, ≤ N/час, ≤ M/сутки (по видам)
                        • state: NORMAL / SLOW / BLOCKED / WAIT_HUMAN / COOLDOWN / PAUSED / HALTED
                        • persist: avito_traffic (день × вид), traffic_state (одна строка)
                               │
                        AvitoBrowserProvider  (одна рабочая вкладка на сессию браузера)
                               │
                             Avito
```

`BrowserGate` остаётся (один Chromium), но **Scanner не вытесняет идущий прогон**: если замок занят — тик
мониторинга пропускается (лог + счётчик), а не закрывает браузер прогона.

## 2. AvitoTraffic

```python
class AvitoTraffic:
    async def acquire(self, kind: str) -> None
        # kind: warmup | search | card | profile | recheck | monitor
        # 1) state HALTED → raise TrafficHalted;  PAUSED/COOLDOWN → ждать до конца (с проверкой stop)
        # 2) бюджет: суточный общий и по виду (card/recheck/profile) → raise BudgetExhausted
        # 3) часовое окно (deque времён за 60 мин) → ждать до освобождения
        # 4) интервал: last + base × slow_factor × uniform(0.5, 1.5) → sleep
        # 5) записать навигацию (счётчики в памяти; в БД — пачкой раз в минуту и на выходе)
    def on_ok(self) -> None                 # SLOW → NORMAL после SLOW_HOURS без блоков
    def on_block(self, reason) -> str       # 'wait_human' | 'pause' | 'halt'; blocks_today += 1
    def on_human_passed(self) -> None       # → COOLDOWN (5 мин) → SLOW (×2, 2 ч)
    def snapshot(self) -> dict              # телеметрия для прогресса/итога
```

Никакой ускоряющей адаптации: интервал может только расти (блок) и возвращаться к базе (время без блоков) — как
Googlebot. ~120 строк + тесты.

## 3. State machine

| Состояние | Вход | Навигации | Выход |
|---|---|---|---|
| NORMAL | старт / SLOW_HOURS без блоков | интервал `base` | блок → BLOCKED |
| SLOW | после капчи или паузы | интервал `base × 2` | `SLOW_HOURS` без блоков → NORMAL; блок → BLOCKED |
| BLOCKED | 403/429/439/маркеры | **стоп всех** | есть человек и окно видно → WAIT_HUMAN; иначе → PAUSED |
| WAIT_HUMAN | Telegram «🧩 нажми "Продолжить" и пройди капчу» | **0** (опрос DOM той же вкладки раз в 5 с, без reload) | реальная страница Avito → COOLDOWN; таймаут 15 мин → PAUSED |
| COOLDOWN | капча пройдена | 0, 5 мин | → SLOW |
| PAUSED | нет человека / нечего проходить | 0, 60 → 120 мин | → SLOW (повтор той же страницы) |
| HALTED | `blocks_today ≥ MAX_BLOCKS_PER_DAY` (3) | 0 до 00:00 МСК (или `/sweep` вручную = сброс) | новые сутки → NORMAL |

Состояние (`state`, `until`, `blocks_today`, `slow_until`, `day`) — в таблице `traffic_state`, поэтому рестарт бота
посреди паузы **не** обнуляет её (сейчас обнуляет).

## 4. Приоритеты и бюджеты (на сутки)

| Вид | Бюджет | Приоритет | Комментарий |
|---|---|---|---|
| search (sweep) | ~300 | 1 | без него нет рынка |
| card (deep: emerging/модели/baseline/exploit/explore) | 130 | 2 | общий на весь рынок, распределяет sampler (Фаза 4) |
| profile | 10 | 3 | только объявления, идущие в «Исследовать сегодня» |
| recheck | 15 | 4 | раз в сутки, после deep, только AM ≥ 3 / 🔥 |
| monitor (Scanner) | остаток | 5 | не вытесняет прогон; при HALTED/PAUSED не ходит |
| warmup | 1–2 | — | раз на сессию браузера |
| **итого** | **450** | | `AVITO_DAILY_BUDGET` |

Неиспользованное по видам не переносится (простота). Ручной `/report` тратит из того же суточного бюджета —
и честно пишет «сегодня осталось N загрузок».

## 5. Объём: изменения в логике обхода

1. **Классы категорий** (`sweep.py`): quiet (< 25/сут, раз в 2 дня), normal (25–150, инкремент, потолок 4 стр.),
   **large (> 150/сут или `total_count` > 20 000 без истории) — выборка: только стр. 1**. Темп large — по плотности
   стр. 1 (окно времени 50 объявлений), покрытие честно < 1 в радаре.
2. **Карточки**: `/report` перестаёт открывать по 12 на подкатегорию; deep-часть берёт карточки из общего бюджета
   (сэмплер Фазы 4). До Фазы 4 — временно `REPORT_CARDS_PER_SUBCAT=4`.
3. **Профиль продавца**: только для находки, которая идёт в отчёт и чья дата со страницы карточки неточная
   (сейчас — каждому кандидату ≥ 50 vpd).
4. **Перепроверка**: убрать из начала каждого `/report`; отдельный шаг ежедневного прогона после deep, бюджет 15,
   только 🔥/высокое внимание, `last_checked_at` старше 2 суток.

## 6. Браузер: одна рабочая вкладка

| | Новая вкладка на fetch (сейчас) | Одна вкладка на сессию (предлагается) |
|---|---|---|
| Сетевые запросы | те же (кэш и cookies общие у контекста) | те же |
| Страница блока | закрывается, ожидание открывает **новую + goto** | **остаётся на экране**, человек жмёт «Продолжить» там же, бот читает DOM |
| История/sessionStorage вкладки | пусто каждый раз | как у человека в одной вкладке |
| Память | минимальна | растёт → пересоздавать вкладку каждые 100 навигаций и после ошибки |
| Зависшая страница | изолирована | таймаут + пересоздание вкладки |

Решение: одна рабочая вкладка (пересоздаётся при ошибке и каждые 100 навигаций). Главный выигрыш — ожидание капчи
без лишней навигации и понятное человеку окно.

Warm-up: оставить, но один раз на сессию браузера и через `traffic.acquire("warmup")`. Переоткрытия браузера
(вытеснение Scanner'ом) уходят → лишние warm-up исчезают.

## 8. Database additions

```sql
CREATE TABLE avito_traffic (           -- телеметрия по суткам и видам; источник дневного бюджета
  day DATE, kind TEXT,                 -- warmup|search|card|profile|recheck|monitor
  loads INTEGER, blocked INTEGER, seconds_waited REAL,
  PRIMARY KEY (day, kind));
CREATE TABLE traffic_state (           -- одна строка: переживает рестарт посреди паузы
  id INTEGER PRIMARY KEY CHECK (id = 1),
  day DATE, state TEXT, until TIMESTAMP, slow_until TIMESTAMP, blocks_today INTEGER, captchas_today INTEGER);
```
`scan_categories` получает `mode` (incremental | sample) — для честного покрытия в радаре.

## 12. Чего не делаем

Решатели капчи, автонажатие «Продолжить», stealth/подмена TLS-отпечатка (curl_cffi impersonate), внутренние/мобильные
API (`m.avito.ru/api/...`), пулы и ротация прокси, параллельные браузеры. Если суточного объёма в 450 загрузок с
одного адреса окажется мало — правильный следующий шаг не обход, а **сторонний API выдачи** (rest-app.net / ads-api.ru)
или обращение в поддержку Avito по IP.
