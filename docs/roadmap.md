# Roadmap — AvitoHunter → «что выложить под заказ»

Цель продукта: каждый день за минуты понимать, какой товар выложить на Avito «под заказ из Китая»,
чтобы его заказывали, и сколько на нём заработаешь. Сейчас бот закрывает шаг «спрос на Avito»;
шаги «цена в Китае» и «маржа» пока ручные.

## Сейчас (v1, готово 2026-10-03)
- `/report`: обход 209 подкатегорий по карте, свежие (≤ 7 дн) объявления от 10 000 ₽ с ≥ 50 просм/день.
- Копии склеиваются, реальная дата — по профилю продавца, капчу проходит человек (бот ждёт).
- Первые живые находки ночью: брендовые коляски/автокресла (Doona X, Bugaboo, Anex) — 200–280 просм/день.

## Дальше — по пользе для ежедневной работы

### 1. Убрать ручной шаг «найти на goofish» (дни)
- Кнопка/ссылка «🔎 goofish» у каждой находки: из названия берём латиницу (бренд + модель:
  «Bugaboo Dragonfly», «Pioneer DDJ-400») → `goofish.com/search?q=…`. Без модели — ссылки нет.
- Поле `finds.china_price` уже есть: команда «ответом на находку: `¥2300`» → бот запоминает цену.

### 2. Маржа прямо в находке (дни)
- Пресеты веса по категориям (коляска ~10 кг, DJ-контроллер ~5 кг, одежда ~1 кг) + тарифы
  (наземка ~500 ₽/кг, авиа ~3000 ₽/кг, курс 12.2) → «себестоимость ~X, маржа ~Y (Z%)».
- Сортировка находок по марже × спросу, когда цена Китая известна.

### 3. Сигналы спроса точнее (дни–неделя)
- Перепроверять уже найденное через 2–3 дня (дёшево: только находки): исчезло = продано →
  «ушло за N дней». Это самый честный сигнал «люди реально покупают».
- «+сегодня» как скорость (просмотры за сегодня / часы с начала дня).
- Конкуренция: сколько копий + сколько продавцов «под заказ» в той же группе.

### 4. Управление без кода (неделя)
- `/top` — лучшие находки за 7 дней из базы (без заходов на Avito).
- `/export` — все находки файлом (CSV для Excel) в Telegram.
- `/skip <категория>` / `/cats` — выключить ненужные категории, чтобы не тратить на них бюджет.
- Кнопки 👍/👎 под находкой → категории с 👍 проверяются чаще (приоритет обхода учится на тебе).

### 5. Надёжность доступа к Avito (по необходимости)
- Блоки сейчас из-за VPN (Рига, адрес хостинга). Лучшее решение — пустить avito.ru мимо VPN
  (split tunneling в Happ) или российский мобильный прокси (`AVITO_PROXY`, ~1–3 тыс ₽/мес).
- Счётчик блоков в `/status`: сколько раз за неделю просили капчу — видно, когда пора менять адрес.

### 6. Автоматическая цена с goofish (недели, риск)
- Связать с FishRadar/goofish-poc: поиск по латинскому запросу → медианная цена ¥.
  Блокер: h5api.m.goofish.com через VPN нестабилен (см. goofish-poc). Делать после п.1–2.

## Потом — если захочется продавать как сервис
- Продукт = **услуга выкупа**, а не софт: бот — внутренний инструмент. Продавать «радар» другим
  перекупам рискованно (правила Avito, блоки растут с числом пользователей, нет API goofish).
- Если всё же SaaS: узкая ниша, бот в Telegram, оплата Stars/ЮKassa, общий кэш одинаковых запросов,
  сервер 24/7 + прокси. Сначала 5–10 бесплатных бета-пользователей из своих TG-чатов.
